# 算对账三账体系 (Triple-Ledger System)

## R — 原文 (Reading)

> 「在算账方式上需要发生三个变化:第一,经营上,不能只算效率账,还要算体验账。第二,产品上,不能只算'订单利润'账,还要算'用户价值'账。第三,营销上,不能只算流量和转化率的账,还要算影响用户决策过程的整体账。」
>
> — 《种草》 第三部分 第3章 04节,「算对营销账」

---

## I — 方法论骨架 (Interpretation)

种草时代(用户先被内容激发、再主动搜索、再比较决策)与传统电商时代(看见即买)的算账逻辑完全不同。本框架要求企业并行跑三套账,而不是只算其中一账:

- **体验账(经营维度)**: 不只看人效/坪效/转化效率,还看"投资于用户感受"是否提升了体验指标(主动好评率、NPS、复购、推荐意愿)。效率是分母,体验是分子;分母太大、分子萎缩,品牌必死。
- **用户价值账(产品维度)**: 不只看订单利润,还要算「LTV + 影响力价值 + 建议价值」。一个用户在生命周期内的全部贡献包含:他持续购买产生的 LTV、他发布内容影响他人带来的获客效率提升(影响力价值)、他给出建议帮助产品迭代带来的隐性收益(建议价值)。只看订单利润会砍掉所有"赔钱但赢得人心"的动作。
- **营销全链路账(营销维度)**: 不只看 T+1 即时转化,还要算「(T+X) ROI + 因指标 + 品牌力指数」。T 是当天、X 是该品类的真实平均决策周期(美妆精华≈29 天、香水≈60 天以上、洗碗机≈7 天)。因指标(产品词搜索量、品牌词搜索量、加购、互动量)衡量策略方向是否对;果指标((T+X) ROI + 品牌力)衡量实际收益。

三账配套运行的本质:每个预算评审、每个营销动作、每个产品立项都必须**同时跑这三套账,任何一账不达标都不应直接否决/通过**,而是先查其他两账再做决策。算账方式决定组织行为;只算一账的组织,会系统性地把种草动作砍光。

配套的预算纪律:种草预算按 4 阶段投资法追加——「验证机会 → 验证产品 → 营销覆盖 → 心智占领」每阶段必须达到标准才进入下一阶段,未达标即停。三账体系是这套预算纪律的"账目底盘",(T+X) ROI 是它的时间锚,品牌力指数是它的最终衡量。

## A1 — 书中的应用 (Past Application)

### 案例 1: 阿芙精油的「因果指标 + 用户价值账」抗住 2 年低谷 (c04/c44)
- **问题**: 阿芙精油 2011-2012 年靠淘宝流量红利崛起,2016 年小乙加入后任 CMO → COO → CEO。她推动从"追逐流量风口"转向"以油养肤"战略,砍掉 1000 个 SKU 中的 900 个(700 人减到 200 人,SKU 从 1000+ 减到 100+)。阿芙 11 籽精华油作为新战略的爆品,上市后整整 2 年销量没打开。
- **方法论的使用**: 按三账体系诊断:如果只看订单利润账或 T+1 流量账,11 籽精华油必然在 6 个月内被砍。小乙用**因指标**(产品词搜索量、品牌词搜索量、互动量、加购量)持续观测——指标虽然缓慢,但呈上升趋势;用**用户价值账**解释"虽然单笔订单不赚钱,但用户分享比例高、复购潜力大";用**(T+X) ROI**(美妆精华 X≈29-45 天)抗住 CFO 的"为什么不砍"质疑。
- **结论**: 阿芙 11 籽精华油慢慢打开市场,2022 年底 CFO 终于相信「以油养肤」战略。阿芙回到 2011-2012 年巅峰期收入和利润,沉淀了清晰的品牌心智。
- **结果**: 验证了「单账 ROI 不达标不能直接砍预算,要查其他两账」——11 籽精华油的 2 年低谷期恰好对应品牌力指数的爬坡期,如果当时按 T+1 ROI 砍掉,后续的爆款效应不复存在。

### 案例 2: 某美妆精华的「(T+X) ROI」验证种草内容长尾 (c59)
- **问题**: 某美妆精华品牌投放种草内容,按 T+1 数据看,转化很差;某同期投放的洗碗机品牌,T+1 数据同样难看。营销总监面临"是否立即停投"的决策。
- **方法论的使用**: 按三账体系的营销全链路账诊断,先用**因指标**看种草内容对用户的主动行为推动——某美妆精华产品,种草内容直到第 45 天还在带来大量新增成交用户;某洗碗机产品,种草内容直到第 7 天成交用户数才开始陡增。两个品类**真实决策周期**完全不同:美妆精华 X≈29-45 天、洗碗机 X≈7 天。用 (T+X) ROI 评估后,两个品类的营销 ROI 都达标,只是回报时间窗不同。
- **结论**: 「看见即买」的转化逻辑在长决策周期品类失效。如果用 T+1 ROI 卡死,会砍掉所有需要用户"先被激发、再主动搜索、再比较决策"才能成交的品类动作。
- **结果**: 验证了 (T+X) ROI 指标的必要性——不同品类决策周期差异要求不同的度量方法;也验证了「决策周期长 ≠ 种草效果慢」——种草内容长尾效应本身是健康的、可预期的、应被纳入 ROI 计算的回报。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **预算分配评审**: 用户提出"营销部申请 200 万预算,值不值",需要按三账评估而非单 ROI。
2. **新品立项 ROI 论证**: 用户问"这个新品要不要上",需要按 4 阶段投资法分阶段评估,每阶段达标才追加。
3. **种草内容 ROI 评估**: 用户说"这条种草笔记投了 5 万,T+1 只带来 10 单,要不要停?"——需要按品类决策周期 (T+X) 评估。
4. **产品定价**: 用户问"这款新品怎么定价、毛利率多少",需要算用户价值账(LTV + 影响力 + 建议)而非只看订单利润。
5. **品牌投入评估**: 用户说"品牌广告 ROI 算不清,还投不投?"——需要品牌力指数做长期账目衡量。
6. **内容被砍预算的解释**: 用户说"为什么我们部门做的'好内容'被砍预算,而促销内容反而获得资源"——三账体系能解释这是单账决策的必然结果。

### 语言信号 (用户的话里出现这些就应激活)

- "营销 ROI 怎么算 / 这个预算值不值 / 新品要不要上 / 为什么好内容被砍"
- "(T+X) ROI / 决策周期 / T+1 数据 / 即时转化 / 转化率"
- "因果指标 / 因指标 / 果指标 / 品牌力指数 / 用户价值账 / 体验账"
- "三账 / 三账体系 / 算对账 / 算账方式 / 预算分阶段 / 4 阶段投资法"
- "种草周期 / 种草效果多久 / 评估时点 / 多久出效果"

### 与相邻 skill 的区分

- 与 `user-value-formula` 的区别: `user-value-formula` 是**用户层级**的算账公式(LTV + 影响力价值 + 建议价值,衡量单个用户的全部价值);本 skill 是**账目层级**的算账体系(三套账并行,衡量整个组织在不同维度上的资源分配)。一个谈"怎么算一个用户的价值",一个谈"怎么算整个公司的账"。
- 与 `experience-management-loop` 的区别: `experience-management-loop` 是**组织运转维度**(体验循环 vs 效率循环并行运转);本 skill 是**预算与算账维度**(在体验循环运转时,用什么账目来评估它)。三账体系是体验管理循环能跑起来的"账目底盘"。
- 与 `planting-champion-7steps` 的区别: 7 步骤是**变革路径**(从找到原点到建立制度的 7 步操作);本 skill 提供变革第 7 步「建立制度」时所需的预算与算账制度。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下三步执行:

### 步骤 1: 建立三账指标体系 (一次性基建)

1.1 **体验账指标**: 列出体验账的 3-5 个核心指标——主动好评率、NPS、推荐意愿(净推荐值)、复购周期变化、人均停留/使用时长。这些是"感受是否被激发"的行为代理变量。
1.2 **用户价值账指标**: 按 `user-value-formula` 的公式,把用户拆为三类价值:LTV(订单利润)、影响力价值(分享比例/UGC 量/营销效率提升)、建议价值(用户反馈被采纳数)。每类价值对应一个可观测指标。
1.3 **营销全链路账指标**: 列出
  - **因指标**: 产品词搜索量、品牌词搜索量、加购量、互动量、收藏量、评论量(衡量策略方向是否对)
  - **果指标**: (T+X) ROI(X 按品类决策周期设定,如美妆精华 29 天/香水 60 天/洗碗机 7 天) + 品牌力指数(衡量长期心智)

- **完成标准**: 三账共 9-12 个指标全部有数据源、有责任人、有看板;X 的取值在该品类有明确依据(用户品类平均决策周期,可向平台数据/历史数据求证)。

---

### 步骤 2: 按 (T+X) 周期评估每个预算申请

2.1 **拒绝单账决策**: 收到任何预算申请(营销/产品/经营),强制要求提交方同时给出**三账预测**:这个动作对体验账、用户价值账、营销全链路账分别的影响是什么?只给单账 ROI(尤其是 T+1 ROI)的申请视为不完整,必须退回补全。
2.2 **按 X 周期评估**: 评估时点严格按该品类的 X 设置——美妆精华内容至少评估到 T+29,香水至少 T+60,洗碗机至少 T+7。X 之前的"低转化"不构成砍预算的理由。
2.3 **因指标先行诊断**: 在 T+X 内,即使果指标((T+X) ROI)未达标,只要因指标(产品词搜索、品牌词搜索、加购、互动)呈上升趋势,**继续追加**(种草动作正在生效)。

🔴 **CHECKPOINT** (关键决策点): 当三账中**任意一账严重不达标**时(例:订单利润持续亏损 3 个月、品牌力指数连续 2 个季度下降、用户分享比例归零),不可直接砍预算/砍动作。**必须先查另外两账是否健康**:
- 若另两账健康(品牌力在爬坡 / 用户复购在上升 / 互动在涨),说明该动作正在投资于未来,应继续;
- 若另两账同步恶化,说明该动作确实失败,进入 if-fail fallback。

---

### 步骤 3: 阶段投资,每阶段达标才追加

3.1 **分 4 阶段管理预算**: 任何种草项目的预算都按以下 4 阶段追加:
  - **阶段 1 验证机会**: 观察用户是否被普遍激发(因指标验证)→ 通过率标准:核心人群自发展开搜索/加购/分享
  - **阶段 2 验证产品**: 用户乐于分享、无严重问题(产品词搜索+用户价值账验证)→ 通过率标准:分享比例 > 基线,且无重大负面舆情
  - **阶段 3 营销阶段**: 覆盖决策路径内容((T+X) ROI 验证)→ 通过率标准:果指标开始正向
  - **阶段 4 心智占领**: 建立品牌力指数测量机制(品牌力指数验证)→ 通过率标准:品牌力指数进入目标人群 Top 3
3.2 **每阶段必须达到标准再追加**: 未达标的阶段,**不进入下一阶段**,也**不追加预算**——这是反"先用预算换增长"的纪律。

🛑 **STOP 信号** (错误路径停止): 出现以下任一信号立即停手,不进入下一阶段:
- 阶段 1 因指标连续 4 周无上升趋势(用户未被普遍激发);
- 阶段 2 用户价值账持续恶化(分享比例/复购/建议价值都在掉);
- 阶段 3 (T+X) ROI 在 X+30 天后仍未达盈亏平衡(品类决策周期已超,仍无回报)。

---

### if-fail fallback (失败三段式)

当某预算动作 / 某个阶段被判定失败时,按以下三段式兜底:

1. **一线修复 (失败触发条件 + 立即修复)**: 问"是指标定义错 / 数据采错 / 动作执行错"——若指标定义错,重置三账指标;若数据采错,补采;若动作执行错,纠偏后重测 1 个完整 X 周期。
2. **二线修复 (若一线修复无效)**: 重新做用户价值账审计——是否低估了 LTV / 影响力价值 / 建议价值?若低估,扩展 (T+X) 到 X+30 天再评估;若用户分享比例确实低,先做"用户参与动作"再谈营销。
3. **仍失败兜底 (若二线修复仍无效)**: **放弃该动作,把预算转向其他候选**。**严禁追加更多预算赌翻盘**(种草时代,用户用脚投票,追加只能放大失败)。同时保留该动作的失败档案作为下次立项的反例。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **不适用于产品功能设计**: 三账管的是"评估与资源分配",不解决"做什么产品功能"。功能设计用 `user-experience-formula`、`hit-product-trilogy`。
- **不适用于单次创意发想**: 三账不评估"这条内容好不好",那是内容评审 / `reverse-funnel-strategy` / `planting-org-pyramid` 的工作。
- **不适用于纯用户访谈设计**: 访谈是 `lifestyle-segmentation` / `super-user-collaboration` 的方法,本 skill 是算账。
- **不适用于短期促销 ROI 评估**: 真正短决策周期(食品快消、零食)用 T+1 即可,但应同时跑三账以免被长期价值反噬。

### 作者在书中警告的失败模式

- **ce17 唯 KPI 论,只看销量不看 NPS 与复购(阿芙一年 100 多个品只成 1 个)**: 阿芙早期内部考核只看销量/利润,"赔钱但赢得人心"的动作(品牌内容、口碑沉淀、新品类教育)被砍,导致新品无流程化机制,一年 100 多个 SKU 只成 1 个。**这是三账体系最核心的反例**——只用"订单利润账"做决策,体验账与用户价值账的动作会被系统性砍光。
- **ce28 算账只看即时 ROI,砍掉长期价值动作**: 用 T+1 ROI 评估所有动作,见效慢但长期价值高的动作被系统砍掉,品牌力下滑,几年后企业回头看"曾经种下的内容都消失了"。**这是 (T+X) ROI + 品牌力指数必引的反例**。
- **ce18 用短期效率激励挤压员工对用户的关注时间**: 算法精确控制每个员工动作,挤掉所有空闲,员工无心情无时间关注用户,体验恶化——三账中体验账的指标无法被采集,组织就只剩效率账和流量账。**这是双循环被效率循环吞并的具体机制**。

### 作者的盲点 / 时代局限

- **三账指标的可信度风险**: 体验账与品牌力指数的指标(NPS、品牌力调研、分享比例)易被"刷出来",作者未深入讨论如何防止数据造假与组织内"美化报表"的博弈。落地时需要配套内部-外部双标准(见 `internal-external-dual-standard`)与第三方数据源交叉验证。
- **品类决策周期 X 的取值难题**: 作者举例美妆精华 29 天、香水 60 天,但未给出"如何测算本品类 X"的具体方法(如:首次种草接触到首次购买的 P50 间隔?还是 P80?)。落地时需要用本企业历史数据 + 平台数据反推,而非拍脑袋。
- **未充分讨论 B2B 场景**: 三账体系主要面向 B2C 种草场景,B2B 决策周期更长(可能 6-18 个月)、决策人多(采购/技术/财务/业务)、影响者与决策者分离——直接套用会失效。落地时需为 B2B 场景单独设计 X 的取值与因指标(如:技术方案下载量、试用申请数、POC 完成数)。
- **未配套"砍预算失败"的责任机制**: 三账体系让"不砍预算"成为正确动作,但若持续追加仍失败,组织内谁来承担?作者未讨论责任归属,落地时应配套明确的失败止损线与责任人制度。

### 容易混淆的邻近方法论

- **vs OKR / Balanced Scorecard**: 三账体系是种草场景下的"算账语言",OKR 是目标管理框架,BSC 是战略评估框架。三账更聚焦"经营/产品/营销三个具体领域的预算与 ROI",OKR/BSC 更聚焦"目标对齐与战略地图"——三账可作为 BSC 的具体落地账目,但不能替代 BSC 的战略对齐功能。
- **vs Triple Bottom Line(三底线)**: TBL 是社会/环境/经济三重底线,用于 CSR 评估;三账体系是体验/用户价值/营销全链路三账,用于种草预算评估。两者"三"字相同但内涵不同——TBL 关心"企业对社会的外部责任",三账关心"企业内部的种草算账纪律"。
- **vs 财务三表(资产负债/利润/现金流)**: 三账体系不是替代财务三表,而是"在种草业务层增加的三套评估账目"。它服务于"做什么/投什么/砍什么"的日常决策,财务三表服务于"整体盈利/偿债/流动性"的法定披露。
- **vs 单 ROI 思维**: 单 ROI 思维把"投资回报率"等同于"利润 ÷ 投入";三账体系认为"投入回报"有三种不同的时间窗与价值形态(短/中/长),必须分别评估——**单 ROI 思维是本 skill 的最大混淆对象,所有"只算一账"的论证都属于此类**。
